# Прототип «Облачное видеонаблюдение»

Самодостаточный статический прототип продуктового модуля ЦПК для МегаФон B2B.

## Как открыть

Откройте `index.html` в браузере. Сборка и зависимости не нужны.

## Как залить в GitHub

1. Создайте репозиторий.
2. Загрузите файлы `index.html`, `styles.css`, `app.js`, `README.md`.
3. Для GitHub Pages выберите публикацию из корня репозитория.

## Что реализовано

- Лендинг с hero, преимуществами, тарифами, бизнес-сегментами, FAQ и финальным CTA.
- Переключение тарифных сегментов с продуктовой логикой.
- LeadModal, TariffConnectModal и OTP-сценарий.
- Checkout flow из трех шагов со sticky summary.
- Подсказки организаций и адресов, ветвление для ООО/ИП и зоны монтажа.
- Success-state заказа и имитация скачивания счета.
